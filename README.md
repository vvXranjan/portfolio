## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/vvXranjan/portfolio.git
```

### Navigate to the project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open **http://localhost:5173** in your browser.
