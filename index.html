GenAI Career Copilot 2026

Smart ATS: Resume & JD Intelligence Platform

An end-to-end resume–JD intelligence system where deterministic services stay the source of truth for scoring and skill matching while the LLM only orchestrates and explains — it never fabricates a skill. A 9-node LangGraph Career Copilot analyzes resume/JD pairs, explains ATS scores, finds gaps, and drafts grounded resume suggestions and interview prep, with the same capabilities exposed as 11 MCP tools over stdio. PostgreSQL holds structured truth; ChromaDB powers RAG and job-recommendation retrieval, backed by async Kafka ingestion. On a 30-pair hand-labeled evaluation set, the hybrid ATS scored 0.839 Spearman rank correlation against human labels and 0.767 Recall@5 on retrieval. Covered by 240 passing tests.

Multi-Agent Incident Response 2026

Distributed Agentic Incident & Security Response Engine

A multi-agent, event-driven pipeline over Kafka that investigates production incidents, gating escalation with a z-score detector plus an LOF-based ML anomaly gate to suppress transient noise. A two-phase Investigator Agent separates sandboxed MCP tool execution from tool-free LLM analysis to keep evidence provenance verifiable, retrieves historical precedent from ChromaDB, and drafts — but never executes — a remediation plan: every action is gated behind human approval via Slack and a FastAPI/React dashboard, with requires_approval hard-set in code, never accepted from model output. Multi-Agent Orchestrator
